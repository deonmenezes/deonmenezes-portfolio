Important APIs: official starting list

A practical list of official API entry points for AI, payments, email, messaging, data, authentication, maps, source control, and deployment.

Pick APIs by the capability your product needs, read the official authentication and limits pages, and test the smallest server-side request before adding a full SDK.

Use this safely

A practical starting checklist

  1. 01

    Define the user outcome first; do not add an API because it is popular.

  2. 02

    Read the provider's official quickstart, authentication, rate-limit, pricing, and webhook-security pages.

  3. 03

    Keep credentials server-side, use the narrowest permissions available, verify webhook signatures, and budget for retries and outages.
