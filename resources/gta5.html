GTA 5 in a browser tab:
what happened.

On 6 October 2026 a site called playgta5.com let people play Grand Theft Auto V inside Chrome, with nothing to install. It spread across X in a morning and was offline within hours. Here is what it was, how it worked, where it stands now, and which other games are still online in a browser.

The short version

What happened.

This was an unofficial project. It was not made or released by Rockstar Games.

  1. 01

    It spread in one morning.

    Clips of GTA V running inside Google Chrome went viral on X on 6 October. One demo, from the account Pixel Gamer 4K, showed it on an Apple M3 Pro laptop. PCQuest reported that post at 1.5 million views.

  2. 02

    It ran on your own device.

    This was not cloud gaming, where the game runs on someone else's computer and you watch a video stream of it. The browser downloaded about 700 MB first, according to the reports, then pulled in more as you played. People reported a Story Mode and a Sandbox Mode, and some said it ran on phones.

  3. 03

    It was offline within hours.

    Visitors started getting errors and blank pages the same day. When I checked on 6 October the site returned a Cloudflare 522 error, which means the server behind it was not answering.

Under the hood

How it worked.

The Internet Archive's Wayback Machine saved a copy of the site's front page on 6 October. The game itself is not in that copy, but the page's own code and the developer notes inside it describe the design. This is what they say.

Part 1 The engine

  1. The game engine was compiled to WebAssembly. WebAssembly is a format that lets code written in languages like C++ run inside a browser at close to full speed.
  2. It ran in Web Workers, not on the page. A Web Worker is a background thread in the browser. Each engine thread got its own worker, and the notes put each one at about 20 MB.
  3. The page itself did very little. It showed the loading screen and handed its drawing surface, the canvas, to the workers.

Part 2 Graphics, sound and controls

  1. A separate GPU worker drew every frame through WebGPU. WebGPU is the browser's modern way of talking to the graphics card.
  2. Sound went through shared memory. The engine's audio mixer wrote into a block of memory, and a small audio script in the browser played it.
  3. Controls went the other way. Keyboard and mouse events were written into shared memory for the engine to read.

Part 3 Fitting a huge game into a tab

  1. Game data was streamed as needed. A dedicated worker fetched files on demand and kept its own store in the browser. The notes measure about 1.2 to 1.4 GB of game data for the world to load the first time.
  2. Weak devices got a low-memory mode. On devices reporting 4 GB of memory or less it used fewer threads, lower detail and no shadows. The notes say this cut graphics memory from 1.16 GB to 0.5 GB.
  3. The loading screen was rebuilt in HTML. The notes say it was ported from the game's own start-up screen.
Posts on X said the port was made with AI coding tools. I could not confirm who made it or which tools were used.

Right now

Where it stands.

  1. 01

    Nobody has confirmed why it went down.

    Windows Report found no confirmation from Rockstar Games or its owner Take-Two that they ordered it taken down. Other coverage puts it down to the traffic.

  2. 02

    It was never a licensed copy.

    Several outlets reported that it was built on leaked GTA V source code. That has not been confirmed. Either way, the site was serving Rockstar's game to anyone for free, and Take-Two has had browser versions of its games removed before, including a Vice City port.

  3. 03

    There is no working link to share.

    The live site is down, and the Wayback Machine copy holds only the title screen, so it never gets past loading. I'm not linking to mirrors. Sites that copy a viral page like this are a common way to spread malware.

Update · 9 October 2026

GTA 5 is offline. 24 other games are still online.

Black Ops Zombies, Halo, Skate 3, GTA Vice City, Quake and more now have their own page, each with a screenshot and a link.

If you want to play

How to play GTA V.

The official ways still work.

  • Buy it from Rockstar. The official page lists every platform it is sold on: rockstargames.com/gta-v.
  • No gaming PC? Check whether a cloud gaming service you already use carries it. That is the legal way to play on a weak laptop or a phone.
  • Be careful with "play GTA 5 free" sites. If a site asks you to install something or sign in, close it.

For builders

Build this kind of thing.

The same browser technology is open to everyone.

  • WebAssembly. Start at webassembly.org, then use Emscripten to compile C or C++ for the browser.
  • WebGPU. MDN's WebGPU guide covers drawing with the graphics card from a web page.
  • Web Workers. MDN's Web Workers guide explains running heavy code off the main page.
