From the Reel · Instagram Edits for Mac

How to make Claude edit your videos in Instagram Edits.

The Edits app for Mac has a built-in connector for AI agents. Switch it on, paste one command, and Claude Code, Codex or Muse can cut, caption, grade and export your videos inside Edits.

Get Edits for Mac ↗ Jump to the setup › 

# Edits copies this for you, with your own token filled in
claude mcp add --transport http --scope user metapilot-native http://127.0.0.1:19501/mcp --header "Authorization: Bearer <YOUR_TOKEN>"

Step 1 · Turn it on

A few clicks in Edits.

You need a Mac with Apple silicon (M1 or later). Edits for Mac is free and you sign in with Instagram.

  1. Install Edits for Mac.Download it from edits.instagram.com/desktop, open it and sign in with your Instagram account.
  2. Open Settings, then the Automation tab.Turn on Enable Automation Server. It lets AI clients control Edits on this Mac over a local connection.
  3. Copy the command for your agent.Under Connect an AI client there is a ready-made setup for Claude Code, Codex and Muse, with your Access token already in it.

Step 2 · Connect your agent

Paste it, then restart the agent.

The connector is called metapilot-native. It only answers on your Mac, and only while Edits is open.

  • Claude Code

    Run the copied command in Terminal, then start a new Claude Code session. 
    claude mcp add --transport http --scope user metapilot-native http://127.0.0.1:19501/mcp --header "Authorization: Bearer <YOUR_TOKEN>"

  • Codex

    Run both copied lines in the same Terminal window before you launch Codex. 
    export METAPILOT_TOKEN=<YOUR_TOKEN>
codex mcp add metapilot-native --url http://127.0.0.1:19501/mcp --bearer-token-env-var METAPILOT_TOKEN

  • Muse

    In Muse settings, replace the edits entry under mcpServers with the block Edits copies, then start a new Muse session.

Use the command Edits copies, not this page's. The address above is what my Mac shows (port 19501). Edits lets you change the port, so the copied command is always the right one. <YOUR_TOKEN> is a placeholder. Any other agent that speaks MCP works too: streamable HTTP, that URL, and an Authorization: Bearer header.

Step 3 · Edit

What worked on my edits.

The tools follow the screen Edits is on. On the home screen the agent sees projects, new project, open project and import. Editing tools appear once a project is open.

  • Start with getCapabilities. It tells the agent how time, the canvas and the tools work before it touches anything.
  • Import video with importMedia and a file path on the Mac. addMedia is for audio only (music, sound effects, voiceover).
  • Captions: generateCaptions with source video, then setCaptionStyle Word Highlight for the word-by-word look.
  • Cuts, text and looks: splitAt, trim and delete for cuts, addText, filters, effects, transitions and setColorGrade. previewVideoFrames lets the agent look at its own work.
  • Export: setExportSettings takes the resolution as width x height, like 1080x1920, then export.
  • One app, many agents. Every connected agent drives the same app. Save the project and check which project is open before exporting.

First prompt to try

Use the metapilot-native tools. Call getCapabilities first. Make a new Edits project, import ~/Movies/clip.mov with importMedia, cut the silences, add Word Highlight captions, then export at 1080x1920 and tell me where the file is.

Optional · Run it 24/7

Text your agent, the Mac does the edit.

The connector never leaves your Mac, so leave the Mac on and reach it safely instead of opening the port.

  1. Keep the Mac awake with Edits open.Plug it in. Running caffeinate -i in Terminal stops it sleeping while that window is open.
  2. Run your agent on the Mac and message it from your phone through whatever remote chat you use with it. Nothing else to set up.
  3. Or connect from another computer.Turn on Remote Login on the Mac, put both machines on a private network such as Tailscale, open an SSH tunnel, then add the same command there. 
    ssh -N -L 19501:127.0.0.1:19501 you@your-mac

Keep in mind

The token is the key to your projects.

  • Keep the Access token private. Anyone with it can edit your projects while the server is on. If it leaks, regenerate it in the Automation tab and paste the new one into your agent.
  • Never expose port 19501 to the internet. Edits listens on the Mac itself only. Use an SSH tunnel, not port forwarding.
  • Posting: Edits shares straight to Instagram from the app. My tests through the connector covered editing and exporting, so check what getCapabilities offers on your version, or tap share yourself.
  • Checked on Edits for Mac 454.0.0, 9 November 2026. Menu and tool names can change between updates.
