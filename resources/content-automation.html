The skills

The skills behind my content. Free.

A skill is a .md playbook that tells Claude how you like things done. These are copies of the ones my setup runs on: editing, motion, posting, comment-to-DM, YouTube and ideas. Each zip has the SKILL.md, its scripts and a README.

  1. Download a zip.One skill, or all of them in one file.
  2. Unzip it into ~/.claude/skills/You end up with ~/.claude/skills/<name>/SKILL.md.
  3. Ask Claude Code for it by name.For example: "use the video-edit skill on this clip". Read the SKILL.md once and change the parts about my setup to yours.

Made for my own machine and accounts, so paths, ids and account names are placeholders like YOUR_INSTAGRAM_TOKEN and <your-folder>. No keys, tokens or passwords are included. Only text and code: fonts, images, videos and model files are left out, and some steps point at tools or other skills of mine that are not in the zip.

1 · The basics

Claude works best with four things.

Give Claude these and it stops being a chatbot. It becomes your editor, your publisher and your assistant.

  • APIsA door into an app.
  • MCPsA plug-in made for AI.
  • CLIsA command in the terminal.
  • SkillsA .md playbook that tells Claude how you like things done.

3 · Posting to every platform

One video, four platforms.

  • Instagram: the Graph API posts reels and pulls stats. Content Publishing docs ↗
  • YouTube: the Data API posts Shorts and full videos. videos.insert docs ↗
  • TikTok: API posts stay private until TikTok audits your app. Content Posting API ↗
  • X: API posting costs money (pay-per-use credits). X API pricing ↗

No free API? Use a Chrome extension. With Claude in Chrome, Claude opens the page and clicks Post for you. The post-video skill above does exactly this for TikTok and X.

4 · Prompt in, finished reel out

These are real prompts I sent.

  • Do the usual edit, motion graphics... animations like this would be better.Plus a link to a cartoon video I liked. That became my Meta Muse reel: 871K views.
  • Make it more animated please... my face will be there.That became my iPhone Duo reel, posted Oct 17.
  • Show animations of the technology... colour marking and circle how it works, handwritten.That became my Quidich visit on YouTube Shorts.

That's the whole brief. No timeline, no keyframes.

6 · How Claude Code decides how to edit

It picks the path with the fewest dependencies.

Give it a prompt and references and it weighs the options:

  • A. Install a new app (3 new things to set up)
  • B. A cloud video API (a key, an upload, a bill)
  • C. What's already on my PC (ffmpeg, Whisper, HTML)

Almost always C.

9 · The full automation loop

Record. Upload. One message.

  1. My PC is always on
  2. Claude Code runs on my phone
  3. I record
  4. I upload to Drive
  5. I message: "Uploaded. Edit it like..."
  6. It's edited and posted

On top of that, every reel gets comment-to-DM. Someone comments a word like "GHOST", and they get an auto DM with the link (deonmenezes.com/resources/ghost). That is the reel-automation skill.

Every edit ends with one question from Claude:

"Ship it, or change it?"
